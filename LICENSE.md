## 1. THE ZERO-KNOWLEDGE MANDATE

* **Cryptographic Self-Sovereignty**: No modification or derivative work of this software may introduce telemetry, tracking, or network-bound diagnostics that expose unencrypted user data, filenames, file contents, or master keys to any server, third party, or cloud infrastructure.
* **In-Memory Encrypted Privacy**: Any derivative works of this software MUST respect the memory hygiene patterns of this vault. Plaintext master keys or master passwords shall remain strictly in transient, volatile application memory (or native secure cryptoprocessors/biometric keystores) and must never be committed to disk or persistent storage in unencrypted format.
* **Absolute local-first execution**: All cryptographic operations, key derivations (including PBKDF2 iterations), and symmetric AES-GCM data sealing MUST take place client-side within the local sandboxed runtime or secure boundaries of the user's personal hardware.
